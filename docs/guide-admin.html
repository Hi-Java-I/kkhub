一、系统简介

本系统用于商机提交与资源匹配：销售同事提交客户需求（商机），系统根据各分组的资源档位，自动返回「资源是否充足」以及对应分组的资源与服务质量情况；资源管理同事维护分组信息、资源档位和服务质量指标。

角色能做什么
普通用户下载方案资料、查看线路说明、提交 / 编辑自己的商机、查看匹配结果、查看分组信息（只读）
技术人员只读查看：资源清单（不显示服务质量数值）、各分组服务质量折线图（缓存命中率 / TTFT（P50） / 有效成功率，与用户侧一致）、分组信息；不能修改任何内容，也看不到商机和 BD有话说
管理员以上全部，另加：资源看板、资源清单（档位与服务质量指标）、分组信息维护、同步资源情况、用户管理、系统设置
访问地址：http://kkaihub.northsea.site:5002（建议使用 Chrome 或 Edge 浏览器）。

二、登录与安全

  1. 账号由管理员统一开通，不支持自行注册。拿到用户名和初始密码后，在登录页输入即可。
  2. 无操作自动退出：一段时间不操作（默认 10 分钟）会自动退出，到点前会弹窗提醒，点「继续停留」可延长。
  3. 忘记密码：普通用户不能自行修改密码，请联系管理员重置。
  4. 同一账号连续输错密码 10 次会被锁定 15 分钟。
本系统内容仅限公司内部使用：页面带有姓名和时间水印，禁止截图、录屏、复制外传，操作会被记录。账号请勿转借他人。

三、普通用户操作 普通用户

1. 下载方案资料

页面最上方点击「《快快AIHub-企业LLM统一接入解决方案》点击下载」，即可下载方案 PPT，用于给客户介绍。

2. 线路说明

线路适用场景超时时间
https://ai-api.kkidc.com用户在国内接入900s
https://api.ai.kkidc.com用户在国外 / 香港接入1800s

每张线路卡片上有「复制地址」按钮，可直接复制给客户。

3. 资源冗余推荐

如果页面出现绿色的「资源冗余，可尽快挖掘商机」板块，说明其中列出的分组资源量充裕（TPM 3000w 以上），可以优先向客户推荐这些分组对应的模型。

4. 提交商机

  1. 点击欢迎横幅上的「+ 提交商机」，或商机清单右上角的「+ 新增商机」。
  2. 按下表填写后点「保存」：
字段填写说明
客户名称 *客户或项目名称
场景 *coding 场景 / 蒸馏场景
需求模型厂商 *从列表中选择；列表里没有的选「其他」后手动填写
需求模型ID *可多选：选择厂商后列出该厂商的模型，勾选需要的模型（可「全选」/「清空」）；列表里没有的，在下方「其他」里填写，多个用逗号分隔。选了多个模型时，TPM / RPM 需求按所选模型平均分摊来判断资源是否充足
TPM / RPM 需求量 *可直接选择档位（TPM：500w-1000w / 1000w-2000w / 2000w-3000w / 3000w-5000w / 5000w以上；RPM：500-1000 … 5000以上，w = 万），也可选「手动填写」输入具体数值
预计上量时间 *1天内 / 3天内
填写日期 *默认当天，可修改
需求背景客户需求背景、场景等补充说明（选填）

5. 查看匹配结果

保存后会自动弹出「商机匹配结果」，并自动保留；之后随时可在商机清单中点「查看匹配结果」（显示最后一次编辑后的结果）。结果包括：

  • 资源情况：资源充足 / 资源紧张 / 资源冗余，含义见第五部分。
  • 对应分组及资源档位：需求模型所在的各个分组，以及各分组的 TPM / RPM 档位、缓存命中率、TTFT（P50）、有效成功率。
  • 对应分组实际情况折线图：最近 24 小时每小时的缓存命中率、TTFT（P50）、有效成功率；点击图上方的分组名可显示 / 隐藏该分组。
折线图数据仅供参考，向客户承诺前推荐让客户接入实测。

6. 编辑 / 删除商机

商机清单只显示自己提交的商机，每行可「编辑」或「删除」。列表每页 5 条，底部可翻页。

7. 查看分组信息

「分组信息」表列出所有模型厂商、分组、模型ID、资源来源、分组说明和参数说明；可用上方「筛选」按模型厂商、分组快速查找。

四、管理员操作 管理员

1. 资源看板

  • 顶部数字：资源分组数、在途商机数、紧张 / 缺口分组数、需提前扩容数、冗余可售数。
  • 「资源紧张度匹配」：按分组展示容量与商机需求，默认收起，点「展开」查看，每页 6 张。
  • 「资源容量 vs 商机需求」：TPM、RPM 两张折线图，横轴为分组，鼠标悬停看数值。

2. 分组信息维护

  • 新增 / 编辑：填写模型厂商、分组、模型ID（一行一个，可填多个）、资源来源、分组说明、参数说明。
  • 批量上新：点「⤓ 批量上新」，上传 CSV 或从 Excel 直接粘贴（支持 WPS / Excel 导出的文件）。同一「模型厂商 + 分组」会合并，已存在的分组会追加模型ID。可先「下载 CSV 模板」照着填。
  • 同步资源情况：每个分组可设置「资源紧张 / 资源充足 / 资源冗余」，用于没有选档位时给商机返回结果。
  • 删除分组会同时删除资源清单里对应的那一行。

3. 资源清单（档位与服务质量）

资源清单与分组信息一一对应：新增分组后自动出现对应一行，无需单独新增。每行操作：

  1. 选择档位：选 TPM 档位、RPM 档位；可同时填写缓存命中率（%）、TTFT P50（秒）、有效成功率（%）和每小时波动幅度（±1% / ±5%）。保存后填报日期自动记为当天。
  2. 折线图：查看该分组最近 24 小时的服务质量情况。
  • 「模型厂商 / 分组名称 / 资源来源」在资源清单和分组信息之间双向同步，改任意一边都会同时生效。
  • TPM 档位为「3000w-5000w」「5000w以上」的分组，会在用户侧显示为「资源冗余，可尽快挖掘商机」。
  • 服务质量折线图：系统以填写的值为基准、按所选波动幅度生成每小时数据；修改后从当前小时起按新值计算。请按实际情况定期更新。
  • 「⤓ 批量填报 TPM/RPM」：按模板一次填写多个分组的档位和指标。

4. 商机管理

  • 管理员可看到所有人提交的商机，「匹配状态」为系统真实测算结果。
  • 「同步资源情况」下拉默认「自动」（按档位或分组设置）；也可对单个商机手动指定，手动指定优先。
  • 每行「查看匹配结果」可看到与用户相同的结果弹窗和折线图。

5. 用户管理

  • 新增用户：填写用户名、显示名、角色（普通用户 / 技术人员 / 管理员）、初始密码（至少 6 位，可点「🎲 随机生成」）。
  • 批量添加用户：点「⤓ 批量添加用户」，按「用户名, 密码, 显示名, 角色」上传或粘贴；用户名已存在、密码不足 6 位的行会跳过并提示原因。
  • 重置密码：编辑用户，在「登录密码」填新密码即可；留空表示不修改。
  • 管理员不能修改自己的角色（防止误操作锁死），可通过右上角「修改密码」修改自己的密码。

6. 系统设置

可设置无操作自动退出的时长（分钟）和提前提醒的秒数。

五、BD有话说 / 产品有话说

「BD有话说」是商务同事向公司反馈一线信息的渠道，方便资源和产品同事及时了解客户与市场情况。

可以说什么

类型适合填写的内容（举例）
需求反馈客户想要的模型、用量、时间要求、对延迟 / 稳定性的要求等
行业了解行业动态、竞品价格与做法、客户所在行业的典型场景
资源了解听到的资源渠道、价格变化、供应情况等

怎么提交

  1. 点欢迎横幅上的「💬 BD有话说」，或页面「BD有话说」板块右上角的「💬 我要说」（顶部导航也可直接跳到该板块）。
  2. 选择类型，填写内容（最多 2000 字），点「提交」。
  3. 提交后可在「BD有话说」列表看到，列表只显示自己提交的内容，每页 5 条，可删除自己的内容。
建议写清楚：客户 / 行业、具体需求或信息、时间、信息来源，便于后续跟进。

产品有话说

技术人员专用的反馈渠道，类型为：产品需求 / 问题反馈 / 优化建议。技术人员在页面上方「💡 产品有话说」或「产品有话说」板块提交，只能看到自己提交的内容。

管理员查看 管理员

  • 管理员在「BD有话说」「产品有话说」两个板块分别看到所有商务、所有技术人员提交的内容，每条显示提交人和提交时间。
  • 可按提交日期（起止）、类型、提交人筛选，每页 5 条，可翻页；不需要的内容可删除。

📢 公告栏 管理员

用于向技术人员发布 KK AI Hub 平台上新的功能和问题汇总。只有管理员可以填写，技术人员只读，普通用户看不到。

  1. 在「公告栏」板块右上角点「＋ 发布公告」，填写：类型（新功能 / 问题汇总）、填写时间、标题、内容；可选模型厂商和分组（分组随厂商联动，从分组信息中选择）。
  2. 指定了分组的公告，会自动附上该分组的对应分组信息（模型ID、资源来源、分组说明、参数说明）；只指定厂商时，附上该厂商下的所有分组；分组信息修改后公告里同步更新。
  3. 每条公告可「编辑」「删除」。列表按填写时间倒序，每页 5 条。
  4. 筛选：类型、填写时间（起止）、模型厂商、分组、关键词（标题 / 内容）。

六、名词与状态说明

名词说明
TPM / RPM每分钟 Token 数 / 每分钟请求数；w = 万（如 1000w = 1000 万）
缓存命中率请求命中缓存的比例，越高越省成本、响应越快
TTFT（P50）首字延迟的 P50（中位数）：从发出请求到收到第一个字的时间，一半的请求不超过这个值，越低越好
有效成功率请求成功返回的比例
商机资源情况含义与建议
资源充足需求在对应分组的资源档位范围内，可正常推进；后台会根据需求进行资源统计及扩容
资源紧张需求超过对应分组的资源档位，推进前请先与资源负责人确认可承接量
资源冗余资源充裕，可优先推进、尽快上量

七、常见问题

页面没显示最新内容？

按 Ctrl + F5 强制刷新后重新登录。

提示「登录已超时」？

长时间未操作被自动退出，重新登录即可。

需求模型ID 下拉里找不到想要的模型？

选「其他」手动填写；同时可联系管理员在分组信息中补充该模型。

匹配结果折线图显示「暂未填写」？

说明对应分组还没录入服务质量指标，请联系管理员在资源清单中填写。

遇到其他问题？

请联系系统管理员。
